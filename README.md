# clinic-ai-receptionist-multilingual
AI Clinic Receptionist — Speaks Urdu/Sindhi/Hindi, Writes English Records
The first AI receptionist that understands South Asian patients in their mother tongue but writes professional English records for doctors.
 Features
- ✅ Speaks: Urdu, Sindhi, Hindi, English (input)
- ✅ Writes: Professional English (output for records)
- ✅ Tools: Patient history DB, Bill calculator, Doctor availability
- ✅ Built on Gemini 2.5 Flash Lite — fast, no 503 errors
- ✅ 30 lines Python — deploy in 1 day

### Tech Stack
Python, Google GenAI SDK, Gemini 2.5 Flash Lite, Automatic Function Calling, SQLite (can switch to Google Sheets)
